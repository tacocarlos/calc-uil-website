# arTIfiCE

Unmodified release files of [arTIfiCE](https://github.com/YvanTT/arTIfiCE) by YvanTT, a jailbreak that lets
TI-84 Plus CE calculators on OS 5.5 and later run C/assembly programs like KEYPAD. Licensed GPL-3.0 (see
LICENSE); source at https://github.com/YvanTT/arTIfiCE.

| Folder | Release | For calculator OS |
|---|---|---|
| `v2.1/` | [v2.1](https://github.com/YvanTT/arTIfiCE/releases/tag/v2.1) (`arTIfiCE_v2.1.8xp`) | 5.5 to 5.8.4 |
| `v3/` | [v3](https://github.com/YvanTT/arTIfiCE/releases/tag/v3) (`arTIfiCE.8xp` + `INEQUVAR.8xv`) | 5.8.5 only |

OS 5.4 and earlier don't need it. Install steps: https://yvantt.github.io/arTIfiCE/
