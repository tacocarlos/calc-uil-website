    How to connect a TI-84 Plus CE
    1. With the calculator on the home screen and plugged in, click Install KEYPAD on calculator. You only need to do this once.
    2. Run prgmKEYPAD from the home screen.
    3. Plug the calculator into this computer and click Connect calculator.
    4. Press on on the calculator to stop keypad mode.
